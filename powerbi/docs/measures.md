# Measures

Generated by `tools/spec.py`. Grouped by display folder.

## Check-ins

*Drive* · table `Responses` · format `#,0` · Donor check-ins (form responses after de-duplication).

```dax
Check-ins =
COUNTROWS ( Responses )
```

## Units Collected

*Drive* · table `Responses` · format `#,0` · Units of whole blood collected.

```dax
Units Collected =
CALCULATE ( [Check-ins], Responses[donated] == TRUE () )
```

## Deferrals

*Screening* · table `Responses` · format `#,0` · Check-ins turned away at screening (blank for the Donated reason, so bar charts leave it out).

```dax
Deferrals =
CALCULATE ( [Check-ins], Responses[donated] == FALSE () )
```

## Donation Rate

*Drive* · table `Responses` · format `0%` · Share of check-ins who donated.

```dax
Donation Rate =
DIVIDE ( [Units Collected], [Check-ins] )
```

## Deferral Rate

*Screening* · table `Responses` · format `0%` · Share of check-ins deferred.

```dax
Deferral Rate =
DIVIDE ( [Deferrals], [Check-ins] )
```

## First-timer Share

*Drive* · table `Responses` · format `0%` · Share who had never donated before.

```dax
First-timer Share =
DIVIDE ( CALCULATE ( [Check-ins], Responses[first_time] == TRUE () ), [Check-ins] )
```

## Measurable Check-ins

*Return* · table `Responses` · format `#,0` · Check-ins at drives that have a later drive, so return can be measured.

```dax
Measurable Check-ins =
CALCULATE ( [Check-ins], Responses[has_later_drive] == TRUE () )
```

## Promised Return %

*Return* · table `Responses` · format `0%` · Said they would come back.

```dax
Promised Return % =
DIVIDE (
    CALCULATE ( [Check-ins], Responses[has_later_drive] == TRUE (), Responses[will_return] == TRUE () ),
    [Measurable Check-ins]
)
```

## Actual Return %

*Return* · table `Responses` · format `0%` · Were seen at a later drive.

```dax
Actual Return % =
DIVIDE (
    CALCULATE ( [Check-ins], Responses[has_later_drive] == TRUE (), Responses[came_back_later] == TRUE () ),
    [Measurable Check-ins]
)
```

## Return Gap

*Return* · table `Responses` · format `0" points"` · Promise minus reality, in percentage points.

```dax
Return Gap =
( [Promised Return %] - [Actual Return %] ) * 100
```
